## `nestjs-zod`

- https://www.npmjs.com/package/nestjs-zod
- https://github.com/BenLorantfy/nestjs-zod

1. ✨ Create nestjs DTOs from zod schemas
2. ✨ Validate / parse request body, query params, and url params using zod
3. ✨ Serialize response bodies using zod
4. ✨ Automatically generate OpenAPI documentation using zod
5. ✨ Supports zod codecs
